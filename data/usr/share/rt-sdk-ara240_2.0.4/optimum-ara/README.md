# Optimum-Ara

<h4> Accelerated inference with NXP's Ara240 </h4>

[![license](https://img.shields.io/badge/License-Apache%202.0-blue)](./LICENSE.txt)

---
<div align="left">

Optimum-Ara is an extension of the Hugging Face [Optimum](https://github.com/huggingface/optimum) library that integrates with Ara240 DNPU to enable accelerated inference for optimized Ara240 models.

</div></div>

The following models are supported by `optimum-ara`:

- Qwen2.5-Coder-1.5B
- Qwen2.5-VL-7B-Instruct
- Qwen2.5-7B-Instruct
