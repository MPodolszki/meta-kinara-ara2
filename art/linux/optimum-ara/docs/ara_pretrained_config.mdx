# AraPretrainedConfig APIs

To use **AraPretrainedConfig** class, we import it from `optimum.ara` in the below mentioned way.

```python

from optimum.ara import AraPretrainedConfig

```
**AraPretrainedConfig** serves as a base class that includes standard methods for loading or saving model configurations from a local file, directory, or a pretrained source.

Below is the list of APIs

- [`from_pretrained()`](#from_pretrained)
- [`update_ara_dict_params()`](#update_ara_dict_params)
- [`from_json_file()`](#from_json_file)
- [`from_dict()`](#from_dict)
- [`make_ara_config()`](#make_ara_config)

## from_pretrained()

Provides the list of Ara specific configurations and returns an instance of **AraPretrainedConfig**.

```python
.from_pretrained(
        cls,
        pretrained_model_name_or_path: Union[str, os.PathLike],
        cache_dir: Optional[Union[str, os.PathLike]] = None,
        force_download: bool = False,
        local_files_only: bool = False,
        token: Optional[Union[str, bool]] = None,
        revision: str = "main",
        dvm_path: str = "",
        **kwargs,
    ) -> "AraPretrainedConfig"
```
  
### Arguments:

| Arguments | Description |
| --------- | ----------- |
| `pretrained_model_name_or_path(Union[str, os.PathLike])` | Can be a string, the model id of a pretrained model configuration, a directory path with a saved configuration, for example, using `save_pretrained()`, or a direct path/URL to a JSON config file. |
| `cache_dir(Optional[Union[str, os.PathLike]])` **(unsupported for now)** | Directory path to cache the downloaded model configuration if the default cache location is not used. |
| `force_download(bool)` **(unsupported for now)** | Whether or not to force the (re-)download the model weights and configuration files and override the cached versions if they exist. Defaults to False. |
| `local_files_only(bool)` **(unsupported for now)** | If True, loads only local files without attempting to download from remote sources. Defaults to False. |
| `token(Optional[Union[str, bool]])` **(unsupported for now)** | Token used for HTTP bearer authorization when accessing remote files. If set to True or left unspecified, a default token is used. |
| `Revision(str)` **(unsupported for now)** | Specifies the version of the model to use. Can be a branch name, tag, or commit ID, as models are stored in git. |
| `dvm_path(str)` | Model DVM path.  |
| `**kwargs` | Additional configuration values that override existing settings when loading the model. |

### Returns:

```python

return cls(ara_cfg=ara_cfg, **config_dict)

```
This returns an instance of **AraPretrainedConfig**, `ara_cfg`, a structured config object created from Ara-specific settings. And `**config_dict`, the complete original configuration dictionary.

### Example:

Test loading a causalLM config from local directory using
AraPretrainedConfig.from_pretrained(). Assumes model is compiled into dvm format.

```python

# Import the os module 
import os

# Import necessary classes and enums from the configuration utilities of the optimum.ara module
from optimum.ara.configuration_utils import (
    AraConfig,              # Base configuration class
    AraPretrainedConfig,    # Configuration class for pretrained models
    InterfaceType,          # Enum class representing supported interface types
)

# Define a test function to verify configuration loading from a directory
def test_config_loading_from_config_dir(self):

    # Load the configuration from the specified model directory using from_pretrained
    config = AraPretrainedConfig.from_pretrained(
        os.path.realpath("models/llama2-7b") 
    )

    # Assert that the loaded config is an instance of AraPretrainedConfig
    assert isinstance(
        config, AraPretrainedConfig  
    ), 


```

## update_ara_dict_params():

Updates the Ara-specific parameters sent as `kwargs` in `from_pretrained` API.

```python
    .update_ara_dict_params(cls, ara_dict, **kwargs):
```

### Arguments:

| Arguments | Description |
| --------- | ----------- |
| `ara_dict` | Dictionary of all the Ara specific attributes that make up this configuration instance. |
| `**kwargs` | Additional configuration values that override existing settings when loading the model. |

### Returns:

```python

return ara_dict

```
`ara_dict` returns the updated Ara specific parameters sent as `kwargs`.

## from_json_file()

Loads **AraPretrainedConfig** directly from the json_file with configuration details passed in the function.

```python

    .from_json_file(
        cls, json_file: Union[str, os.PathLike]
    ) -> "AraPretrainedConfig":

```

### Arguments:

| Arguments | Description |
| --------- | ----------- |
| `json_file (Union[str, os.PathLike])` | Path to the JSON file containing the parameters. |

### Raises:

- `AssertionError`:
    - Raised when the specified json_file path is incorrect, file is missing, or wrong config directory used.

### Returns:

```python
return cls(ara_cfg=ara_cfg, **config_dict)

```

### Example:

This returns an instance of **AraPretrainedConfig**, `ara_cfg`, a structured config object created from Ara-specific settings. And `**config_dict`, the complete original configuration dictionary.

```python

# Import the os module
import os

# Import necessary classes and enums from optimum.ara configuration utilities
from optimum.ara.configuration_utils import (
    AraConfig,              # Base configuration class for Ara models
    AraPretrainedConfig,    # Configuration class for pretrained Ara models

)

    # Define a test method to verify configuration loading from a JSON file path
    def test_config_loading_from_config_path(self):
        

        # Load configuration directly from the specified JSON file path
```

## from_dict()

Loads **AraPretrainedConfig** directly from the dictionary passed in the function. It builds a config object from a dictionary instead of a file.

```python

.from_dict(cls, config_dict, **unused_kwargs):

```
### Arguments:

| Arguments | Description |
| --------- | ----------- |
| `config_dict` | Dictionary that is used to instantiate the configuration object. |
| `**unused_kwargs` **(unsupported for now)** | It is a dictionary containing key values from kwargs that were not used to update the configuration, representing keys that are not recognized as config attributes |

### Returns:

```python

return cls(ara_cfg=ara_cfg, **config_dict)

```

This returns an instance of **AraPretrainedConfig**, `ara_cfg`, a structured config object created from Ara-specific settings. And `**config_dict`, the complete original configuration dictionary.

### Example:

```python

# Import the os module
import os
import json

# Import necessary classes and enums from optimum.ara configuration utilities
from optimum.ara.configuration_utils import (
    AraConfig,              # Base configuration class for Ara models
    AraPretrainedConfig,    # Configuration class for pretrained Ara models
    InterfaceType,          # Enum for different interface types
)

# loading AraPretrainedConfig directly from a dictionary instead of a file
def test_config_loading_from_dict(self):

    # Load the config dictionary from a JSON file
    with open(os.path.realpath("models/llama2-7b/config.json"), "r") as f:
        config_dict = json.load(f)

    # Create the config object directly from the dictionary
    config = AraPretrainedConfig.from_dict(config_dict)

    # Verify that the loaded config is of type AraPretrainedConfig
    assert isinstance(
        config, AraPretrainedConfig
    ),
```


## make_ara_config()

Creates and returns an **AraConfig** object using provided or default values. This function builds an **AraConfig** object with complete communication and device settings for inference.

```python

   .make_ara_config(
        cls,
        inference_device: str = DEFAULT_INFERENCE_DEVICE,
        dvm_path: str = "",
        interface_ip_address: str = DEFAULT_IP_ADDRESS,
        interface_port: int = DEFAULT_PORT,
        interface_named_pipe: str = DEFAULT_NAMED_PIPE,
        interface_socket_file: str = DEFAULT_SOCKET_PATH,
        interface_type: InterfaceType = DEFAULT_INTERFACE_TYPE,
    ) -> AraConfig:

```
### Arguments:

| Arguments | Description |
| --------- | ----------- |
| `inference_device (str)` | Device to run inference on. |
| `dvm_path (str)` | DVM file path used by the model. |
| `interface_ip_address (str)` | IP address for network-based inference communication. |
| `interface_port (int)` | Port number for communication. |
|`interface_named_pipe (str)` | Named pipe path used in Windows/IPC. |
| `interface_socket_file (str) `| UNIX domain socket path for local communication. |
| `interface_type (InterfaceType)` | Enum or custom type defining which communication interface to use. For example, socket, http, and pipe. |

### Returns:

```python

return AraConfig(
    inference_device=inference_device,
    dvm_path=dvm_path,
    interface_ip_address=interface_ip_address,
    interface_port=interface_port,
    interface_named_pipe=interface_named_pipe,
    interface_socket_file=interface_socket_file,
    interface_type=interface_type,
)

```

Returns an instance created for the **AraConfig** class using all the parameters.  This holds all the configuration values related to running the model inference. All values are passed either from the user or default constants.

### Example:

```python
# Import os module 
import os

# Import configuration-related classes and enums from optimum.ara
from optimum.ara.configuration_utils import (
    AraConfig,              # Configuration class for runtime inference settings
    AraPretrainedConfig,    # Configuration class for pretrained Ara models
    InterfaceType,          # Enum for different types of inference interfaces (e.g., SOCKET, HTTP)
)

# Import default constants used in optimum.ara inference configuration
from optimum.ara.utils.constants import (
    DEFAULT_INFERENCE_DEVICE,  # Default device used for inference (e.g., CPU, GPU)
    DEFAULT_IP_ADDRESS,        # Default IP address for the interface
    DEFAULT_NAMED_PIPE,        # Default named pipe
    DEFAULT_PORT,              # Default port for socket-based interface
    DEFAULT_SOCKET_PATH,       # Default Unix socket file path
)

    # Define a test function to validate AraConfig creation using default values
    def test_ara_config_creation(self):


        # Create an AraConfig instance from a given DVM path using the AraPretrainedConfig utility
        config = AraPretrainedConfig.make_ara_config(
            dvm_path=os.path.realpath("models/llama2-7b") 
        )

        # Assert the object returned is an instance of AraConfig
        assert isinstance(
            config, AraConfig
        ),

        # Check if the inference device is set to the default value
        assert (
            config.inference_device == DEFAULT_INFERENCE_DEVICE
        ),

        # Check if the default interface port is used
        assert (
            config.interface_port == DEFAULT_PORT
        ), 

        # Ensure the interface type is set to SOCKET by default
        assert (
            config.interface_type == InterfaceType.SOCKET
        ), 

        # Verify that the IP address matches the default setting
        assert (
            config.interface_ip_address == DEFAULT_IP_ADDRESS
        ), 

        # Check that the named pipe is set to the default
        assert (
            config.interface_named_pipe == DEFAULT_NAMED_PIPE
        ), 

        # Confirm that the default socket file path is used
        assert (
            config.interface_socket_file == DEFAULT_SOCKET_PATH
        ),

```
